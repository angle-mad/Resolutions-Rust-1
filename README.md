# Description
I followed the week 1 tutorial and made a Hacker News CLI. It displays the title the points it has, and the author/link to the story. What I added was that I made it so that it displays the number comments the story recieved as well which is next to the points it recieved. This was my first time using Rust but the Tutorial was easy enough to follow and made me start to like the language.
